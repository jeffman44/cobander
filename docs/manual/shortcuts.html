Keyboard shortcuts

Press ? inside Cobander for this sheet. On a Mac, Ctrl means Cmd.

Screens

Ctrl+1 … 5Write · Record · Mix · Practice · Band
KPractice
F1help mode on / off; press twice for the glossary
?this sheet

Transport

Spaceplay / pause (stops recording)
Rrecord onto the armed track
Escstop, and jump back to where you started playing
Home / Endstart / end of the song (Home goes to the loop start when looping)
, .back / forward a bar (Shift: 4 bars)
1 – 9jump to that part of the song
Shift+1 – 9loop that part
Lloop on / off (loops the part you're in)
[ ]loop start / end at the playhead
BA/B against a tagged version (in Mix: before / after Auto mix)
Ttuner

Takes

clickselect a take (a second click on the selected track moves the playhead there)
Ssplit the selected take at the playhead
Mmute / un-mute it
← →nudge a beat (Shift: a bar)
Deldelete it
Ctrl+C / X / Vcopy / cut / paste at the playhead
Ctrl+Dduplicate right after
Shift-dragdrop a copy on another track
Alt-dragignore snap for this drag
right-clickkeep, comp, star, tighten, pitch check, lyrics from this take…

Song

Ctrl+Ssave
Ctrl+Z / Ctrl+Shift+Zundo / redo
↑ ↓select the track above / below
Ppin the next lyric line at the playhead
Ctrl+wheelzoom the timeline (snap follows the zoom)
Alt+wheel over the trackstrack height
Enter in a note threadsend the reply (Shift+Enter = new line)

Practice

Spaceplay / pause (count-in first if on)
← → or , .back / forward a bar
Page Up / Page Downprevious / next part
1 – 9jump to a part (Shift: loop it)
Lloop the part you're in
Mmix: take tracks out / solo one
Vvocals on / off
- / +slower / faster (same pitch)
Cclick on / off
Rrecord
↑ ↓text size
Shift+↑ ↓previous / next song (setlist)
Escclose

Note editor and Melody window

click-drag on empty spacedraw a note (snaps to the grid)
drag a note / its right endmove it / stretch it
double-clickadd or delete a note
↑ ↓move the selected note (Shift: an octave)
Ctrl+Dduplicate the note right after itself (keep pressing to stamp copies)
Shift-drag a notedrag a copy
Altno snap
right-click a notepower chord, add 3rd / 5th, any chord
Ctrl+wheelzoom time; the grid follows
Spaceplay / stop the loop
Ctrl+Zundo the last note edit

Drum editor

click a squareadd a hit · click again = accent · again = remove
drag acrosspaint hits
Ctrl+Zundo the last edit
